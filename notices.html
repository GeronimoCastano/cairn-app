Replace an LGPL library

You may modify the LGPL libraries, relink Cairn with compatible modified versions, and reverse engineer the combined work to debug those modifications. Cairn's proprietary license does not restrict these rights.

For each distributed release, the public release materials must include matching application object files, a relink script, library source and build instructions, notices, and instructions for signing and installing the modified app. These materials allow library replacement without publishing Cairn's proprietary source.

No App Store release has been published yet. There are no production relink kits to download at this time. Kits and corresponding library source must be published alongside each release before distribution.

Release materials · Request materials for a specific version

Requests for materials are free of charge. Include your app version, build number, and platform. A request route does not replace the obligation to publish the matching materials with each release.

Signing on Apple devices

A rebuilt app needs a new signature. Mac builds can be signed locally. On iPhone, iPad, and Apple TV, personal installation requires Xcode, your own Apple signing identity, a provisioned device, and compatible entitlements. Library changes do not modify Apple's App Store copy. Production installation and purchase-restoration behavior must be verified before release.
