# Cairn public website

Public homepage, privacy policy, support, and third-party notices for Cairn.
Hosted with GitHub Pages at https://geronimocastano.github.io/cairn-app/.

This repository contains website content, not Cairn's proprietary app source.
Serve this folder with any static HTTP server for preview. No build is required.
Support and library-material requests belong in this repository's Issues.
Release-specific library source and relink kits belong in Releases.
